maubase

A Firebase/Supabase alternative you actually own.

Auto-generated REST APIs, OAuth 2.1 for your own users (MCP clients included), realtime subscriptions, file storage, and an admin UI — all compiled into one cgo-free Go binary you build, run, and back up yourself. No dashboard to log into that isn't yours.

  • SQLite, no cgo
  • Single binary
  • Self-hosted, not a cloud account

What ships in the binary

Every table becomes an API. Every user gets a session. Nothing calls home.

Path Feature Detail

/api/data/{table}

Auto REST

Create a table, get paginated CRUD for it — list, get, create, patch, delete — with row ownership via owner_id enforced automatically.

/oauth/*

OAuth 2.1 server

Let your own users authorize third-party apps — MCP clients included — against your API. PKCE mandatory, refresh tokens rotate with reuse detection.

/admin/ui

Admin UI

Create tables, browse and edit rows, run raw SQL in a built-in studio — live, no restart, and nothing extra to deploy or host.

/api/realtime

Realtime

Subscribe to changes on your auto-REST tables. Single-process by default; add MAUBASE_REDIS_URL when you run more than one.

/api/storage/files

File storage

Upload and download endpoints gated by the same OAuth scopes as everything else — no separate object-storage service to wire up.

_policies

Row-level access rules

Declare who can read or write a table beyond simple ownership — per role, per column — without hand-rolling middleware for it.

/api/auth/social/*

Social login

"Continue with Google" and "Continue with GitHub," wired into the same session system as email and password — not a bolt-on.

maubase migrate

Migrations CLI

Scaffold, apply, revert, redo, and diff your schema against what's actually applied. Version history you can read, not a black box.

Why not just use Supabase

Same shape of tool. Different owner.

“Move it, back it up, read the SQL — no migration off someone else's platform.”

Firebase and Supabase are a great deal, right up until you need your data somewhere they don't operate, a compliance boundary they don't meet, or a bill you didn't expect. maubase gives you the same shape of tool — auto-REST, auth, realtime, storage — compiled into one binary that runs on hardware you control.

From zero to an API

Four commands in, one table live.

No dashboard to click through first — the schema, the migration history, and the running server are all right here in the terminal.

shell
$ maubase init
created migrations
created migrations/0001_init.sql
created .env.example
created .gitignore

$ maubase migrate new create_posts
created migrations/0002_create_posts.sql
# edit it, add your CREATE TABLE

$ maubase migrate up
applied 0002_create_posts.sql

$ curl -s localhost:8080/api/data/posts
